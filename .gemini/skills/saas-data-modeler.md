# Skill: saas-data-modeler
## Goal: Maintain a scalable, performant Prisma schema.
## Instructions:
- Use **Indexes** on all foreign keys and frequently filtered columns (e.g., `status`, `createdAt`).
- Implement **soft deletes** where necessary to prevent accidental data loss.
- Strictly follow the `specs/data-model.md` source of truth.
